# Theme

All visual tokens for Pipo Fremantle live in `tokens.css`.

- `--pipo-red` / `--pipo-blue` — Nepal flag colours (used for highlights, buttons, underlines)
- `--pipo-navy` — headers, hero, footer
- `--pipo-gold` — restaurant accent
- `--pipo-cream` — page background

Tailwind colour names (`bg-pipo-red`, `text-pipo-navy`, …) read from these variables. Restyle the site by editing this file, then rebuild or restart Docker.
